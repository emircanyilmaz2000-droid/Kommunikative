# KOMMUNIKATIVE!

**Ausstellung für gesellschaftlich engagiertes Kommunikationsdesign**

KOMMUNIKATIVE! zeigt Abschluss- und Studienarbeiten aus Darmstadt, Würzburg und Düsseldorf. Im Mittelpunkt stehen die gesellschaftliche Verantwortung von Gestaltung und die Möglichkeiten des Kommunikationsdesigns, demokratische Prozesse und soziale Gerechtigkeit mitzugestalten.

Die Ausstellung versammelt unterschiedliche gestalterische Positionen und macht sichtbar, wie Design als Mittel der Kommunikation, Reflexion und gesellschaftlichen Veränderung wirken kann.
